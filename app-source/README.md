# Study focus timer - source

This directory holds the maintainable source for the site deployed at
https://molhm01.github.io/study-focus-timer/ .

The repository ROOT contains the built static files that GitHub Pages serves
(index.html, index-*.js, index-*.css, photo-*.js). Do not edit those by hand;
rebuild them from here.

## Layout

- `index.html`, `package.json`, `vite.config.ts`, `tsconfig.json` - Vite + React + TypeScript project files
- `src/main.tsx` - app entry (plain React mount)
- `src/App.tsx` - the whole timer app (phases, tasks, stats, themes, accents, backgrounds, sounds)
- `src/style.css` - global styles
- `src/photos/*.jpg` - background photos (regenerated by the extractor below)
- `tools/extract-photos.mjs` - rebuilds `src/photos/*.jpg` from the deployed `photo-*.js` chunks

## Rebuild and deploy

From the repository root:

```sh
node app-source/tools/extract-photos.mjs   # only needed once, or after cloning
cd app-source
npm install
npx vite build
```

The build emits flat files into `app-source/dist/` (index.html, one index-*.js
bundle, one index-*.css, and one photo-*.js chunk per background photo - the
photos are base64-inlined on purpose so the whole site is plain text files).
Copy the contents of `app-source/dist/` to the repository root and commit
(git push, or the GitHub web editor: every emitted file is text and under
250 KB). GitHub Pages then republishes automatically from `main` / (root).

## Customizing

- Photos: replace any file in `src/photos/` with your own JPG (around 1024-1600px
  wide keeps the bundle small) and rebuild. The file names are referenced in
  `src/App.tsx` (the photo imports and the background list near the top).
- Durations, themes, accents, sounds: visitors change these in the app's
  settings; everything a visitor picks is stored in their own browser's
  localStorage (keys prefixed `sft:`) and never leaves their device.

## Known capability notes

- Photo upload in settings uses an in-memory object URL: it applies
  immediately but resets on reload (picked photos from the built-in set persist).
- Custom alarm/ambient sound links must be hosted on a CORS-enabled host to play.
- Pinterest import works for public pins/boards only.
