# Study focus timer - source

This directory holds the maintainable source for the site deployed at
https://molhm01.github.io/study-focus-timer/ .

The repository ROOT contains the built static files that GitHub Pages serves
(index.html, index-*.js, index-*.css, thumbs-*.js, photo-*.js). Do not edit
those by hand; rebuild them from here.

## Layout

- `index.html`, `package.json`, `vite.config.ts`, `tsconfig.json` - Vite + React + TypeScript project files
- `src/main.tsx` - app entry (plain React mount)
- `src/App.tsx` - the whole timer app (phases, tasks, stats, themes, accents, backgrounds, sounds, Spotify player, compact mode)
- `src/style.css` - global styles, including the animated background presets
- `src/photos/*.jpg` - full background photos (regenerated by the extractor below)
- `src/thumbs/*.jpg` - small picker thumbnails (regenerated by make-thumbs below)
- `tools/extract-photos.mjs` - rebuilds `src/photos/*.jpg` from the deployed `photo-*.js` chunks
- `tools/make-thumbs.mjs` - rebuilds `src/thumbs/*.jpg` from `src/photos/*.jpg` (uses sharp)

## Rebuild and deploy

From the repository root:

```sh
node app-source/tools/extract-photos.mjs   # only needed once, or after cloning
cd app-source
npm install
node tools/make-thumbs.mjs
npx vite build
```

The build emits flat text files into `app-source/dist/`: index.html, one
index-*.js bundle, one index-*.css, one thumbs-*.js chunk (all picker
thumbnails together) and one photo-*.js chunk per full background photo.
Photos and thumbnails are base64-inlined on purpose so the whole site is plain
text files; photo chunks load on demand only when a visitor picks that
background. Copy the contents of `app-source/dist/` to the repository root and
commit (git push, or the GitHub web editor: every emitted file is text and
under 250 KB). GitHub Pages then republishes automatically from `main` /
(root).

## Customizing

- Photos: replace any file in `src/photos/` with your own JPG (around 1024-1600px
  wide keeps the bundle small), rerun make-thumbs, and rebuild. The file names
  are referenced in `src/App.tsx` (the photo/thumb loader maps near the top).
- Animated backgrounds: CSS-only presets in `src/style.css` (classes
  `ft-anim-aurora`, `ft-anim-meteor`, `ft-anim-waves`, `ft-anim-rainfall`),
  registered in the ANIMATED_BGS list in `src/App.tsx`. They animate transform
  and opacity only, so they stay smooth on phones, and they switch off under
  the visitor's reduced-motion setting.
- Durations, themes, accents, sounds: visitors change these in the app's
  settings; everything a visitor picks is stored in their own browser's
  localStorage (keys prefixed `sft:`) and never leaves their device.
- Music: the settings Music section embeds Spotify's official player
  (open.spotify.com playlist, album, track, show or episode links). Playback
  happens inside Spotify's own iframe: visitors signed in to Spotify hear full
  songs, signed-out visitors hear 30-second previews.
- Compact mode: the 🗕 button (or the M key) collapses the page to a small
  floating timer pill; the timer keeps running. The ⛶ button (or F key) toggles
  fullscreen where the browser supports it.

## Known capability notes

- Photo upload in settings uses an in-memory object URL: it applies
  immediately but resets on reload (picked photos from the built-in set persist).
- Custom alarm/ambient sound links must be hosted on a CORS-enabled host to play.
- Pinterest import works for public pins/boards only.
- Fullscreen uses the browser Fullscreen API; iOS Safari does not support it
  for web pages, so the button is hidden there.
